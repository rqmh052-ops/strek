## ما الجديد في v3؟

| الميزة | v2 (القديم) | v3 (الجديد) |
|--------|------------|------------|
| تسجيل الجلسات | ❌ | ✅ كل جلسة مسجّلة (IP، وقت، رقم، نتيجة) |
| حفظ السجلات | ❌ | ✅ ملف `sessions_log.json` يبقى بعد إعادة التشغيل |
| حماية المشرف | ❌ | ✅ كلمة مرور SHA-256 |
| تشفير كلمات المرور | ❌ كنص واضح | ✅ XOR + Base64 في الذاكرة |
| Rate Limiting | ❌ | ✅ 10 طلبات / 60 ثانية لكل IP |
| التحقق من الأرقام | ❌ | ✅ regex: 01xxxxxxxxx |
| إخفاء الأرقام في السجل | ❌ | ✅ 010****5678 |
| تحديث تلقائي للداشبورد | ❌ | ✅ كل 30 ثانية |
| تلوين السجل | ❌ | ✅ أخضر/أحمر/أصفر |
| زر إعدادات في الهيدر | ❌ | ✅ يفتح لوحة المشرف |

---

## التشغيل

```bash
pip install -r requirements.txt
python main.py
```

ثم افتح المتصفح على: `http://localhost:5000`

---

## لوحة المشرف (الإعدادات)

- اضغط زر **⚙️ إعدادات** في أعلى يمين التطبيق
- أدخل كلمة المرور: **777** (غيّرها في `main.py` السطر التالي):

```python
ADMIN_PASSWORD_HASH = hashlib.sha256("777".encode()).hexdigest()
```

استبدل `"777"` بكلمة مرورك الجديدة.

### ما ترى في لوحة المشرف؟
- **إجمالي الجلسات / الناجحة / الفاشلة**
- كل جلسة تعرض:
  - التوقيت الدقيق
  - IP الزائر (حتى لو من هاتف آخر)
  - الأرقام المستخدمة (مخفية: 010****5678)
  - نوع العملية (يدوي / تلقائي / فشل / دخول مشرف)
  - ملاحظات الخطأ إن وجدت

---

## الأمان

- كلمات مرور المستخدمين **لا تُحفَظ كنص واضح** — تُشفَّر بـ XOR+Base64
- كلمة مرور المشرف محفوظة كـ **SHA-256 hash** فقط
- حد الطلبات يمنع الإساءة: 10 طلبات كل 60 ثانية لكل IP
- الأرقام في السجلات مخفية دائماً
